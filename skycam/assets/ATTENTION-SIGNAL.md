# Canadian alerting attention signal

Source: https://alerts.pelmorex.com/wp-content/uploads/2019/12/Canadian_Alerting_Attention_Signal-8sec.mp3

Retrieved 18 October 2026 from Pelmorex's NAADS resources. Converted to mono 48-kHz signed 16-bit PCM with a 0.55 amplitude multiplier. The original file's padding is retained. The active signal is eight seconds; the decoded file lasts approximately 8.098 seconds. A separate 0.25-second silence precedes synthesized speech.

Use only for eligible, authenticated official emergency messages. Never use for utility outages, music, demonstrations or synthetic public tests. Repeat presentations omit the signal. Non-English alerts are excluded from presentation and speech. First-play history is persisted separately from the bounded audio cache.
