On-screen updates

Only unplanned outages prompt an amber bar. Planned maintenance appears on the outage slide, with no bulletin speech or music ducking. Bulletin speech can lower music. Official alerts take priority.

Schedule outage coverage

Use a Program clock rule with Only with current power outages. Suggested slots: :13, :28, :43 and :58.

Source freshness

Checks run every five minutes. Each feed is monitored independently; failed or stale feeds cannot trigger bulletin bars. An expired restoration estimate does not confirm restored power.
